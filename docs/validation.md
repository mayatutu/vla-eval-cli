# 验证范围

测试入口：`python -m pytest -q`，先安装 `requirements/test.txt`，并让 ffmpeg、ffprobe 位于 PATH。测试使用内存机器人/模型替身和临时文件，不操作实机。

覆盖配置合并与任意任务标识、CLI 计划、会话计次/恢复、模型生命周期、协议边界、模型输出维度与处理语义，以及真实 FFmpeg/Parquet 导出。现场路径、历史 checkpoint 和任务目录依赖已改为隔离的测试输入；不需要复制训练权重才能运行通用测试。

离线通过不代表 GPU 精度、真实控制频率、相机标定或机器人安全已验证。原部署运行经验也不等同于整理版的整机验收。换环境后需独立核对权重和处理器，完成保存观测推理验证，再安排操作者现场验收。

当前发布测试结果见 `validation-results.md`。缺失依赖应在测试环境解决，不能通过删除断言或跳过失败来声称通过。
